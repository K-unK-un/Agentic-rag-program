# 企业员工假期管理实施方案

## 一、总则与合规基础

本方案严格依据《中华人民共和国劳动法》《职工带薪年休假条例》及四川省、成都市现行劳动用工相关规定制定，所有条款均符合合规要求，不存在与现行法律法规冲突的内容。方案适用于公司全体在职人员，覆盖正式员工、试用期员工、实习人员、劳务派遣人员及第三方外包驻场人员，全体人员统一执行本假期管理规则，无特殊豁免权限。
本方案核心目标为建立权责清晰、流程闭环、合规可控的假期管理体系，3个月内实现全员假期规则知晓率100%，假期类劳动争议发生率降至0，既保障员工法定休息权益，也避免因假期安排混乱影响企业正常运营秩序。

## 二、国家法定节假日管理规则

1. 执行标准：严格按照国家统一规定执行全年11天全体公民法定节假日，分别为元旦1天、春节3天、清明节1天、劳动节1天、端午节1天、中秋节1天、国庆节3天。
2. 调休安排：公司结合年度生产运营节奏，在不违反法规的前提下，可对法定节假日前后的周末休息日进行统筹调休，调休方案提前15个工作日向全员公示，保障员工连续休假权益。
3. 薪酬与加班规则：法定节假日期间，员工享受全额带薪休假待遇，公司不得无故克扣员工基础工资；若因业务特殊需求安排员工在法定节假日当日上岗，必须按员工本人日工资标准的300%支付加班报酬，不得以补休形式抵扣法定节假日加班薪资，日工资统一按月计薪天数21.75天进行折算。
4. 特殊适配：部分需24小时值守的岗位，法定节假日排班需提前1个月告知员工，同步做好加班薪资核算与后续轮休的统筹安排，不得强制要求员工无报酬值守。

## 三、带薪年休假管理办法

1. 休假资格与天数标准：员工连续在本公司工作满12个月即可享受带薪年休假，休假天数严格按累计工作年限划定：累计工作满1年不满10年的，年休假5天；累计工作满10年不满20年的，年休假10天；累计工作满20年及以上的，年休假15天。员工需提供社保缴费记录、原单位离职证明等材料佐证累计工龄，经人力资源部核验后登记入档。
2. 休假安排规则：公司每年1月发布全员年度休假计划指引，员工结合自身工作节奏提交个人年休假申请，部门负责人结合岗位工作饱和度统筹审批，优先保障员工在自然年度内完成年休假休假。年休假可一次性连续使用，也可拆分按半天为最小单位分段使用，可与法定节假日、周末连休，最长连续休假时长原则上不超过10天。
3. 结转与补偿规则：年休假最多可结转至下一个自然年度使用，次年12月31日仍未休假的未休天数自动清零。公司确因工作需要无法安排员工休年休假的，需征得员工本人书面同意，对未休天数按员工日工资收入的300%支付年休假工资报酬，其中包含公司已正常发放的月度工资部分，剩余差额部分在年度结束后1个月内统一发放。若员工本人书面主动提出不休年休假，公司仅需正常发放工作期间的基础工资，无需额外支付未休年休假补偿。
4. 限制情形：员工当年存在以下情形之一的，不再享受当年带薪年休假：累计事假20天以上且公司按规定未扣发工资的；累计工作满1年不满10年的年度内累计请病假2个月以上的；累计工作满10年不满20年的年度内累计请病假3个月以上的；累计工作满20年及以上的年度内累计请病假4个月以上的。

## 四、病假与事假全流程申请管理

### 病假管理细则

1. 申请要求：员工因患病或非因工负伤需停工治疗休息的，可申请病假，病假最小申请单位为4小时。申请3天以内病假的，需提供二级及以上医院开具的诊断证明与休假建议；申请3天及以上长期病假的，需额外附医院的治疗记录、缴费凭证等佐证材料。
2. 特殊场景处理：员工突发急病无法提前提交申请的，需在到岗后12小时内补报部门负责人与人力资源部，后续3个工作日内补齐全部病假证明材料，逾期未提交材料的缺勤按事假认定。
3. 薪酬核算：病假期间发放的工资不得低于成都市当年度最低工资标准的80%，具体核算按员工在本公司的工龄执行阶梯标准：本公司工龄不满3年的，病假首日起前7天发放基础工资的70%；工龄满3年不满5年的，前7天发放基础工资的80%；工龄满5年及以上的，前7天发放基础工资的90%；超出7天的长期病假统一按成都市最低工资标准的80%发放。
4. 医疗期保护：员工实际工作年限10年以下且在本公司工作年限5年以下的，医疗期为3个月；5年以上的为6个月；实际工作年限10年以上且在本公司工作年限5年以下的，医疗期为6个月；5年以上10年以下的为9个月；10年以上15年以下的为12个月；15年以上20年以下的为18个月；20年以上的为24个月。医疗期内公司不得依据《劳动合同法》第四十条、第四十一条规定单方面解除劳动合同。

### 事假管理细则

1. 申请要求：员工因个人私事需占用工作时间处理的，可申请事假，事假最小申请单位为4小时。事假需提前1个工作日提交申请，写明请假事由、请假时长、工作交接安排，同步提交给对接同事确认工作交接到位。
2. 审批权限：事假时长在1天以内的，由部门负责人直接审批；1天以上3天以内的，部门负责人初审后流转至人力资源部终审；3天及以上的，需公司分管领导最终签字确认后方可生效。
3. 薪酬核算：事假期间不计发对应时段的岗位基础工资与绩效工资，全勤奖按实际事假时长对应比例扣除，不得额外多扣员工薪资。
4. 年度上限：员工自然年度内累计事假时长原则上不得超过15天，超出部分需提交总经理特批，避免因长期事假影响部门整体工作推进。

## 五、通用审批与归档规则

1. 所有假期申请统一通过公司内部OA系统提交，按预设审批流完成线上签字确认，特殊紧急场景可先通过微信、电话向审批人报备，后续3个工作日内补全线上审批流程，未完成审批的缺勤一律按旷工认定。
2. 人力资源部建立全员假期管理台账，对每位员工的法定节假日休假、年休假剩余天数、年度病假事假累计时长进行动态更新，每月初向全员推送个人假期剩余情况提醒，避免出现超期未休、超期申请的问题。
3. 所有假期申请材料、佐证证明统一归档至员工个人人事档案，永久留存，作为后续薪资核算、劳动关系处置的合规凭证，不得随意删除修改。

## 六、风险与应对

**第一项风险**是员工提交虚假病假证明，可能引发管理纠纷，影响程度评为“中”。应对措施为：人力资源部可通过官方渠道核验医院证明的真实性，一旦发现伪造材料，直接按严重违纪处理，并扣除当事人当月20%的绩效工资。

**第二项风险**是部门集中扎堆申请年休假，可能导致岗位大面积空缺，影响业务正常运转，影响程度评为“中”。应对措施为：各部门需在年初提前做好年度休假排布，确保核心岗位同一时段休假人数不超过岗位总人数的30%，实行错峰安排。

**第三项风险**是假期台账数据更新不及时，可能导致未休年假核算错误，进而引发劳动争议，影响程度评为“高”。应对措施为：每月底由人力资源部安排双人交叉核验全员假期数据，确认无误后同步公示3个工作日，接受全员核对，确保数据零差错。

**第四项风险**是员工长期请病假时，医疗期管理不合规，可能引发用工风险，影响程度评为“高”。应对措施为：建立针对“三期”员工（孕期、产期、哺乳期）和医疗期员工的专项台账，由专人跟进休假时长核算和薪资发放，并严格按法规要求执行医疗期保护条款。
