# 企业公司办公管理全方案

## 一、总则与适用范围

本方案与公司此前发布的考勤管理、薪酬福利、报销管理、培训发展等所有内部制度完全配套统一执行，适用于公司全体在职人员，包含正式员工、试用期员工、劳务派遣人员、外包驻场人员、临时来访办公人员。所有条款均贴合成都本地企业日常办公场景实际需求，核心目标是建立规范有序、高效节约、安全整洁的办公秩序，1个月内实现办公区域资源使用全流程可追溯，办公耗材年度损耗率同比下降10%，既充分保障全体员工日常办公需求，也避免办公资源闲置浪费，防范办公区域消防安全、资产流失等各类风险。 本方案由行政部牵头制定与日常落地执行，各部门负责人作为本部门办公管理第一责任人，配合完成部门内部宣贯与落地，总经理拥有最终审批与调整权限，行政部每季度收集全员反馈完成制度细节优化。

## 二、办公用品全管理办法

### （一）分类与台账管理规则

公司所有办公用品统一划分为三大类，由行政部建立全量动态电子台账，每季度完成一次全盘盘点，做到账实100%匹配：

1. 日常消耗类：包含打印纸、中性笔、文件夹、便签本、回形针、胶带、墨盒硒鼓等低值易耗品，单价均在200元以下，属于高频申领品类。
2. 资产类办公用品：包含笔记本电脑、台式主机、显示器、键盘鼠标、打印机、扫描仪、投影仪、录音笔等单价超过200元的办公设备，全部属于公司固定资产范畴。
3. 特殊专用类办公用品：包含涉密文件载体、行业专用工具、定制化办公物料等，由行政部单独建立专属台账，指定专人专项管理。 所有资产类办公用品统一粘贴唯一专属资产标签，标签上标注资产编号、采购日期、使用人信息，资产标签不得私自撕毁、涂改，一旦发现标签缺失，由当前使用人承担补全与核验责任。

### （二）采购与申领全流程

1. 月度集中采购：行政部每月25日收集各部门下月办公用品需求，统一通过公司定点供应商完成集中采购，批量采购降低成本，禁止任何员工私自采购办公用品后走报销流程，特殊紧急临时采购需提前向行政部提交申请，经审批通过后方可执行。
2. 日常消耗类申领：员工申领日常消耗类办公用品，需在内部行政系统提交申领申请，同品类单人每月申领数量设置明确上限：中性笔每月不超过2支，A4打印纸每月不超过2包，文件夹每月不超过3个，经部门负责人确认后即可到行政部领取，超量申领需额外说明用途。
3. 资产类办公用品申领：员工申领资产类办公用品，需提前提交书面申请，详细说明使用用途、预计使用周期，经部门负责人初审、行政部终审通过后统一配发，旧设备由行政部统一回收、登记入库，不得随意丢弃处置。
4. 特殊专用类申领：涉密载体、专用工具类办公用品，需由部门负责人签字确认，行政部专项登记领用人员信息、使用用途、归还时间，使用完成后必须按时归还核验，不得私自带离办公区域。

### （三）资产全生命周期管理

1. 新资产入库：所有采购完成的办公用品入库前，由行政部核验产品质量、核对采购清单，同步完成资产信息登记，录入公司固定资产管理系统。
2. 使用过程管理：资产类办公用品使用人是第一责任人，负责日常维护与保管，出现小故障优先联系行政部安排维修，不得私自拆解、改装办公设备。
3. 折旧与报废规则：资产类办公用品按3年周期计提折旧，达到使用年限、无法正常维修的资产，由行政部核验后统一走报废审批流程，集中合规处置，不得私自变卖、丢弃。
4. 离职交接核验：员工离职时，必须将名下所有资产类办公用品完整归还行政部，行政部核对资产台账确认无缺失、无损坏后，签字确认资产交接完成，方可进入后续离职流程。如出现人为损坏、资产丢失情况，由使用人按资产剩余折旧价值承担对应赔偿责任。

### （四）节约管控细则

行政部每月统计各部门办公用品消耗数据，向全员公示各部门人均耗材使用量，鼓励双面打印、重复利用可回收办公用品，对年度耗材损耗控制达标且无资产流失的部门，年末给予部门集体绩效奖励。针对打印设备设置默认双面打印模式，非必要不使用彩色打印，从技术层面减少耗材浪费。

## 三、会议室全使用规则

### （一）分级分类管理

公司所有会议室按容纳人数、配套设备划分为三个等级，全部通过内部OA会议室预约系统统一开放预约，不设置任何专属部门独占权限，保障所有员工公平使用资源：

1. 小型洽谈室：容纳6人以内，配套基础桌椅、白板，适用于1对1沟通、小型面试、简短业务对接场景。
2. 中型会议室：容纳10-20人，配套投影、视频会议设备、音响系统，适用于部门内部例会、跨部门业务研讨场景。
3. 大型多功能厅：容纳30人以上，配套高清大屏、专业音响、直播设备，适用于公司全员大会、外部客户宣讲、大型培训场景。

### （二）预约与使用全流程

1. 常规预约：员工使用会议室需提前至少1个工作日在系统提交预约申请，明确使用时段、参会人数、所需设备，预约成功后系统自动向全员公示占用状态，同步发送提醒给预约人。
2. 临时紧急使用：临时紧急会议需使用未被预约的会议室时，可直接联系行政部临时协调，不得强行占用已被他人提前预约的会议室，如遇预约冲突，优先保障外部客户接待、公司级重要会议的使用需求。
3. 签到核验：预约时段开始后15分钟内，预约人未到场使用会议室，系统自动释放该时段资源，其他员工可直接预约使用，避免资源闲置。
4. 使用后清理：会议结束后，使用人必须关闭所有灯光、投影、空调等设备，将桌椅归位，带走所有个人物品与会议产生的垃圾，擦拭干净桌面、白板，恢复会议室初始整洁状态。

### （三）违规与特殊场景处理

1. 预约取消规则：预约成功后如临时取消会议，需提前2小时在系统中释放会议室资源，累计3次预约后未到场也未取消的员工，暂停1个月会议室预约权限，由行政部统筹安排使用。
2. 禁止行为规范：严禁在会议室内进食重异味餐食、乱扔杂物、在白板上乱涂乱画，如发现使用后未清理、设备人为损坏的情况，由预约人承担对应清理、维修责任。
3. 跨部门协调机制：多个部门同时申请同一时段的大型多功能厅，由行政部根据会议重要程度、提前预约时长统筹协调，必要时组织相关部门协商调整时段，避免出现使用冲突。
4. 设备保障：行政部每周对所有会议室的音视频设备、空调、照明完成一次巡检，提前排查故障隐患，会议过程中如出现设备故障，预约人可直接联系行政部，10分钟内安排技术人员到场处理。

## 四、工位全管理规定

### （一）工位分配与异动规则

1. 初始分配：行政部按部门人员编制统一分配固定工位，员工入职时登记工位编号、对应办公资产信息，发放工位钥匙、储物柜钥匙，不得私自调换、占用其他员工工位。
2. 工位异动：部门人员架构调整需批量调整工位的，由部门负责人统一向行政部提交申请，说明调整原因、新工位排布方案，行政部核验通过后统筹完成工位搬迁安排，不得私自挪动工位隔断、办公家具、强弱电线路。
3. 临时工位管理：外来临时驻场人员、短期借调员工的临时工位，由行政部统一安排，登记使用人信息、使用周期，到期后及时收回工位资源。
4. 工位标识：每个工位粘贴专属工位标识，标注员工姓名、所属部门，便于内部沟通对接，员工不得私自撕毁、涂改工位标识。

### （二）工位日常行为规范

1. 桌面整洁要求：员工需保持个人工位整洁有序，桌面仅摆放当前正在使用的办公物品，不得在工位区域堆放大量闲置杂物、私人物品，文件资料分类收纳至文件柜，避免桌面杂乱影响办公秩序。
2. 安全管理要求：严禁在工位区域使用大功率违规电器，包括但不限于电煮锅、电热毯、大功率取暖器，严禁私拉乱接电源线路，所有充电设备使用完成后及时拔掉插头，避免引发消防安全隐患。
3. 公共区域维护：工位所在的开放办公区公共通道、茶水间、休闲区由全体员工共同维护，各部门按划分的卫生责任区每日班前班后完成简单清扫，不得在公共通道堆放纸箱、杂物，堵塞消防逃生通道。
4. 工位私人物品管理：员工的个人贵重物品自行妥善保管，下班时锁好个人储物柜，离开工位时关闭个人电脑、显示器、台灯等设备电源，做好工位安全防护。

### （三）特殊场景与离职交接

1. 长期外出管理：员工连续外出超过3个工作日，需将工位桌面的文件、物品收纳整齐，关闭所有工位电源，避免长时间无人值守出现安全隐患。
2. 卫生巡检机制：行政部每周组织一次全办公区域公共卫生巡检，对工位杂乱、违规使用电器、公共区域堆放杂物的情况登记公示，巡检结果纳入部门月度行政合规评分，占部门绩效权重的5%。
3. 离职交接要求：员工离职时需清理个人工位所有私人物品，将工位恢复至入职时的初始状态，经行政部核验工位资产完好、无遗留杂物、电源全部关闭后，方可完成全部离职交接流程，交还工位钥匙与储物柜钥匙。

## 五、配套公共区域管理细则

### （一）茶水间管理

茶水间内的微波炉、冰箱、饮水机等公共设备，由行政部定期清洁维护，员工带入冰箱的餐食必须标注姓名与放入日期，超过3天未领取的餐食由行政部统一清理，使用微波炉加热餐食时做好防护，避免汤汁溢出污染设备，使用完成后随手清理台面水渍、残渣。

### （二）文印区管理

文印区的打印机、复印机、扫描仪由行政部统一维护，员工打印完成后及时取走自己的文件，避免涉密文件遗落，发现设备卡纸、缺墨等问题及时联系行政部处理，不得私自拆解设备，文印区的废纸统一放入可回收收纳箱，定期集中回收利用。

### （三）休闲区管理

休闲区的沙发、桌椅、娱乐设施供员工工间休息使用，使用完成后将物品归位，带走个人产生的垃圾，不得在休闲区长时间聚集大声喧哗，影响其他区域正常办公秩序。

## 六、监督与保障机制

行政部每月开展一次办公区域全维度巡检，对办公用品流失、会议室使用违规、工位管理不合规、公共区域脏乱差的情况登记公示，相关记录纳入员工个人月度行政合规考核，考核结果占月度绩效权重的5%。所有办公管理相关的采购、维修类支出，严格按公司此前发布的报销管理规则完成核销，所有支出明细每月向全员公示，做到公开透明。员工对办公资源分配、巡检结果有异议的，可直接向行政部提交书面反馈，3个工作日内将得到正式处理回复。 （AI生成）
