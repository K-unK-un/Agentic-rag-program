# 企业员工报销管理细则

## 一、适用范围与合规基础

本方案严格依据《中华人民共和国会计法》、国家税务总局发票管理相关规定及公司此前发布的考勤、假期、薪酬类管理制度配套制定，适用于公司全体在职人员，含正式员工、试用期员工、劳务派遣人员、外包驻场人员，所有条款均符合财务合规要求，与公司现有其他行政制度保持统一执行标准。本方案核心目标是建立“标准明确、流程闭环、凭证合规”的报销管理体系，3个月内实现报销单据合规率100%，报销款项支付时效不超过3个工作日，既保障员工因公支出及时核销，也防范企业财务合规风险。

## 二、差旅报销制度

1. 差旅适用场景：员工因公司业务需求赴常驻地以外城市开展商务对接、项目执行、培训参会等工作，可申请差旅报销，差旅前必须提前在OA系统提交《出差审批单》，明确出差事由、往返时间、行程安排、预估费用，经部门负责人审批通过后方可出行，未提前提交审批的差旅费用一律不予报销。
2. 差旅报销覆盖范围：包含城市间交通费、目的地住宿费、差旅伙食补助费、市内交通费四大类，与出差行程无关的个人消费、娱乐消费、超标准消费部分全部由员工个人自行承担。
3. 特殊情形处理：差旅期间顺路返乡、办理私人事务的，需提前在出差审批单中明确标注，对应时段产生的交通、住宿费用全部由个人承担，公司仅报销公务行程对应部分的合规支出；差旅期间因工作需要产生的商务招待费用，不得混入差旅单据中提交，需单独走业务招待类报销流程。
4. 差旅凭证要求：所有差旅相关的交通票、住宿发票必须为真实合规的官方票据，标注完整的公司抬头与税号，行程单、支付记录需与票据信息完全匹配，不得提交虚假票据、涂改票据。

## 三、日常费用报销流程

1. 报销发起：员工在因公支出完成后15个工作日内，在公司财务报销系统上传对应票据照片，填写费用明细、支出事由、对应项目编号，同步上传支付截图、消费明细清单作为佐证材料，同一笔支出的所有凭证需一次性完整提交，不得拆分多次申报。
2. 层级审批：报销单据先流转至部门负责人处完成初审，确认支出事项真实、与部门业务相关；初审通过后流转至财务部门完成票据合规性核验，核对发票真伪、金额是否符合标准、凭证是否齐全；财务核验通过后提交公司分管领导终审签字，全部审批流程完成后进入付款环节。
3. 款项支付：财务部门在终审完成后的3个工作日内，将报销款项直接划转至员工本人工资卡账户，付款完成后同步推送报销到账提醒，员工可在个人薪资明细中核对对应报销金额。
4. 异常退回处理：报销单据如存在票据不合规、材料缺失、超标准申报等问题，财务部门将写明具体退回原因，直接退回至发起人处补充修正，员工完成材料补正后可重新走审批流程。
5. 年度截止规则：当年12月25日为当年度报销截止日，当年产生的所有费用必须在截止日前提交报销，逾期未提交的跨年费用除特殊情况经总经理特批外，一律不予核销。

## 四、报销标准参照

1. 城市间交通费标准：员工出行可选择高铁二等座、动车二等座、经济舱航班、长途大巴等公共交通方式，职级为部门负责人及以上的人员可选择高铁一等座，如需乘坐飞机头等舱、高铁商务座，必须提前提交总经理特批申请，超出标准的差价部分由个人自行承担。
2. 住宿费标准：按出差目的地城市等级划定，一线城市（北京、上海、广州、深圳）单人住宿标准不超过400元/天，新一线城市（成都、杭州、重庆等）单人住宿标准不超过300元/天，其他地级及以下城市单人住宿标准不超过220元/天，同性两人同行出差需合住标准间，对应住宿标准可在单人标准基础上上浮50%。
3. 差旅补助标准：差旅伙食补助费统一按80元/人/天计发，市内交通费按50元/人/天计发，两项补助无需提交发票，随差旅报销单一并发放，超出天数的补助部分不予核算。
4. 日常办公类费用标准：办公耗材采购、快递费、打印费等常规日常支出，需提前向行政部提交采购申请，核定预算后执行，报销时需附采购清单、快递面单等明细凭证，无对应明细的费用一律不予报销。
5. 业务招待费标准：单次招待费用在500元以内的由部门负责人审批，500元以上3000元以内的经财务部门终审，3000元以上的需公司分管领导签字确认，招待报销需附招待对象、招待事由、消费明细清单，无相关佐证材料的不予核销。

## 五、通用管理规则

财务部门每月末梳理全公司当月报销数据，向各部门推送报销进度提醒，所有报销凭证统一归档留存15年，符合国家财务档案管理要求。如发现员工提交虚假发票、虚报冒领报销款项的行为，公司有权追回全部违规所得，直接记严重违纪，情节严重的依法追究对应责任。
