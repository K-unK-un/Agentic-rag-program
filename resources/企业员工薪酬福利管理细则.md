# 企业员工薪酬福利全方案

## 一、总则与合规基础

本方案严格依据《中华人民共和国劳动合同法》《社会保险法》《住房公积金管理条例》，以及四川省、成都市当地最新劳动用工、社保公积金相关政策规定制定，与公司此前发布的考勤管理、假期管理、报销管理、培训发展等所有内部制度完全配套，适用于公司全体在职人员，包含正式员工、试用期员工、劳务派遣人员、外包驻场人员。 本方案核心原则为“按劳分配、绩优多得、合规透明、动态调整”，所有条款均符合现行法规要求，不存在任何合规风险，核心目标是建立兼具市场竞争力与内部公平性的薪酬福利体系，保障员工合法劳动权益，同时支撑企业年度经营目标落地。 本方案由人力资源部牵头制定与解释，财务部负责薪资核算与资金保障，总经理拥有最终审批与调整权限，每年第一季度完成上年度薪酬福利复盘，结合成都市当年度薪资指导线、行业薪酬调研数据完成年度优化调整。

## 二、年度薪资结构全说明

### （一）年度总薪资构成

员工年度总薪资由固定薪资、浮动薪资、福利薪资三大模块组成，全年核算周期为自然年1月1日至12月31日，所有薪资明细在员工入职时通过《薪资确认单》书面明确告知，无任何隐藏核算规则。

1. 固定薪资：占年度总薪资的70%，按月度全额发放，不受当月部门绩效、公司经营情况影响，保障员工基础收入稳定性。
2. 浮动薪资：占年度总薪资的20%，包含月度绩效奖金、年度年终奖金两个子项，完全与个人工作业绩、部门整体绩效、公司年度经营目标完成情况挂钩，不设固定保底金额。
3. 福利薪资：占年度总薪资的10%，包含法定福利、公司专属福利两类，以货币或非货币形式按月度、季度或年度发放，不计入常规月度固定薪资核算基数。

### （二）固定薪资子项明细

1. 基本工资：严格执行成都市当年度最低工资标准，随成都市官方最低工资调整通知同步更新，是员工薪资的法定保障底线，病假、待岗等特殊场景下的薪资核算均以此为基础底线。
2. 岗位工资：根据员工所在岗位职级、岗位价值核定，公司岗位职级共划分为8级，每级对应10个薪资档位，同职级不同能力的员工可对应不同档位，岗位异动时同步调整对应岗位工资标准。
3. 工龄工资：按员工在本公司连续在岗年限核算，每满1年每月增加50元，最高上限为200元/月，从员工入职满12个月的次月起开始计发，中途离职后重新入职的员工，工龄重新累计计算。
4. 全勤奖：标准为100元/月，自然月内无迟到早退、事假、病假、旷工记录即可全额发放，迟到早退累计超过3次、出现任意缺勤情况，全勤奖全额扣除。

### （三）薪资发放全规则

1. 每月15日通过银行代发形式发放上月完整薪资，遇法定节假日则提前至最近一个工作日发放，不得无故延后发薪。
2. 薪资条同步通过内部系统推送至员工个人账户，明细包含应发合计、代扣社保个人部分、代扣公积金个人部分、代扣个税、实发金额等全部条目，员工可随时核对。
3. 员工如对当月薪资明细有异议，可在薪资到账后3个工作日内向人力资源部提交复核申请，人力资源部需在2个工作日内完成核算核对并给出正式反馈。
4. 薪资核算相关的所有纸质凭证、电子记录统一归档留存，符合国家财务档案管理要求，留存时长不低于15年。

## 三、绩效奖金全管理办法

### （一）月度绩效奖金规则

1. 月度绩效奖金核算基数为员工本人月度岗位工资的30%，最终实际发放金额=绩效基数×月度绩效考核得分/100，绩效考核得分按百分制核算，60分以下绩效奖金按0元发放。
2. 绩效考核维度明确划分为：工作任务完成率（权重60%）、工作质量达标率（权重25%）、团队协作表现（权重15%），不同岗位序列可在此基础上调整细分考核指标，技术序列增加技术创新维度权重，销售序列增加业绩完成率维度权重。
3. 每月末由部门负责人完成考核评分，与员工做一对一绩效沟通，员工签字确认后同步至人力资源部核算薪资，所有考核沟通记录、员工签字凭证统一归入个人绩效档案。
4. 如员工对月度绩效考核结果有异议，可在结果公示后2个工作日内提交绩效申诉，由人力资源部联合绩效评审委员会完成复核，3个工作日内给出最终申诉结论。

### （二）年度年终奖金规则

1. 年度年终奖金核算基数为员工本人1个月的全额月度固定薪资，入职不满1年的新员工按实际在岗月份折算年终奖金基数。
2. 最终实际发放金额=年终奖金基数×个人年度平均绩效系数×公司年度经营系数，公司年度经营系数由总经理办公会根据当年整体营收利润情况确定，区间范围为0-2，全员统一公示。
3. 个人年度平均绩效系数由员工全年12个月的月度绩效考核得分核算得出，年度绩效考核结果为S级的系数为1.5，A级为1.2，B级为1.0，C级为0.5，D级为0。
4. 当年12月31日前主动离职、因严重违纪被公司解除劳动合同的员工，不享受当年度年终奖金；年终奖金统一在次年1月随12月薪资一并发放。

### （三）专项激励补充规则

1. 项目专项奖：针对公司级重点项目，项目验收交付达标后，按项目净利润的5%-10%计提项目奖金，由项目负责人根据成员贡献度分配发放，直接随当月薪资计发。
2. 销售提成奖：销售序列员工按公司发布的《销售提成管理细则》核算提成，回款到账后次月对应发放，提成核算明细由销售部、财务部双重核验确认。
3. 评优专项奖：年度优秀员工、优秀管理者获得者，除颁发荣誉证书外，额外发放2000-5000元不等的现金奖励，同时作为下年度薪资调整的优先依据。
4. 创新贡献奖：员工提出的流程优化、技术创新方案落地后为公司创造直接经济效益的，按年新增效益的10%一次性发放创新奖励。

## 四、社保公积金全缴纳指南

### （一）参保基础规则

1. 公司严格按成都市当地社保、公积金管理部门的规定为全体员工缴纳五险一金，包含养老保险、医疗保险、失业保险、工伤保险、生育保险及住房公积金，自员工入职当日起30日内完成社保增员手续，不得逾期参保。
2. 特殊岗位试用期员工，入职首月先统一购买团队人身意外险，转正后立即补缴试用期内的五险一金，保障员工参保权益不出现断档。
3. 社保公积金缴纳基数按员工本人上年度月平均应发工资核定，新入职员工按其首月全月应发工资作为缴纳基数，基数上下限严格执行成都市社保中心、住房公积金管理中心当年发布的官方标准，不得违规按最低基数申报。
4. 住房公积金缴纳比例统一按成都市官方允许的最高合规比例执行，公司与员工个人按同等比例承担，年度可根据公司经营情况在合规范围内调整缴纳比例。

### （二）缴纳与核验流程

1. 每月5日前，人力资源部完成当月社保公积金增员、减员、基数调整的全部申报工作，提交至社保、公积金官方系统完成审核。
2. 社保公积金个人应承担部分，由公司财务部门在员工当月工资中依法代扣代缴，公司承担部分同步按月足额缴纳至官方账户，不出现拖欠、漏缴情况。
3. 每月缴费完成后3个工作日内，人力资源部向全员推送当月缴费明细，员工可通过成都人社官方APP、住房公积金官方小程序自行核验到账情况，如有异常及时反馈。
4. 员工如因个人原因导致社保公积金无法正常增员，需在入职后3个工作日内提交相关材料配合完成参保，逾期未提交导致的断档问题由员工本人承担责任。

### （三）配套服务指引

1. 员工如需办理社保异地转移、公积金提取、开具参保证明、医保异地就医备案等相关业务，可向人力资源部提交申请，由专人协助对接官方部门完成办理，相关业务办理指引统一在内部行政服务板块公示。
2. 员工生育、工伤、失业时，人力资源部全程协助办理对应待遇申领手续，确保员工依法享受的社保待遇及时足额到账。
3. 如因公司操作失误导致的漏缴、少缴问题，公司将在15个工作日内完成补缴，保障员工社保权益不受损失；员工对社保公积金缴纳明细有异议，可携带本人工资条向人力资源部申请复核。

## 五、补充福利与动态调整规则

1. 法定假期福利：严格按国家及成都市规定执行各类带薪假期，春节、中秋等传统节日为全体员工发放节日礼品或购物卡，三八妇女节为全体女性员工发放专属节日福利。
2. 健康保障福利：每年年中组织全体员工完成一次免费常规健康体检，针对户外作业、特殊岗位员工额外增加专项体检项目，体检费用全部由公司承担。
3. 人文关怀福利：员工结婚、生育时发放对应专属贺礼，员工直系亲属去世时发放慰问金，同时按制度规定享受对应带薪假期。
4. 动态调整机制：公司每年第一季度开展全员年度薪资调整工作，结合员工上年度绩效考核结果、市场薪资水平完成薪资档位调整，年度调薪覆盖比例不低于全员的30%，核心岗位员工调薪幅度不低于10%。
5. 保密管理规则：员工个人薪资数据属于公司机密，严禁员工互相打探、传播薪资信息，一经发现按公司保密制度处置，避免内部薪资公平性受到影响。
