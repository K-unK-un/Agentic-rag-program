# 企业员工考勤管理全方案

## 一、总则与适用范围

本方案严格依据《中华人民共和国劳动合同法》《四川省劳动和社会保障厅关于企业实行不定时工作制和综合计算工时工作制的审批管理办法》，以及成都市本地最新用工政策制定，与公司此前发布的薪酬福利、假期管理、报销管理、培训发展等所有内部制度完全配套统一执行，适用于公司全体在职人员，包含正式员工、试用期员工、劳务派遣人员、外包驻场人员、异地派驻人员。
本方案核心目标是建立清晰透明、合规严谨的考勤秩序，保障正常办公节奏，同时充分兼顾员工合理出勤需求，杜绝考勤规则模糊、权责不清引发的用工风险。所有考勤数据直接关联员工月度绩效、薪资核算、假期核算，是企业人力资源管理的核心基础依据，由人力资源部牵头制定与规则解释，行政部负责考勤系统日常运维，各部门负责人作为本部门考勤管理第一责任人，配合完成日常核验与异常初审。

## 二、基础考勤全规则

### （一）标准工时基础框架

1. 常规标准工时岗位：执行每周5天工作制，每日标准工作时长8小时，周一至周五为正常工作日，周六、周日为法定休息日，每日上下班打卡时间明确为上午9:00、下午18:00，中午12:00-13:30为午休时间，午休时段不计入工作时长。
2. 特殊工时岗位：经成都市人社部门审批通过的销售外勤、长途运维、高频出差类岗位，执行不定时工作制，不设置每日固定打卡时点，以工作任务完成情况作为核心考勤依据，不受每日上下班打卡规则约束。
3. 综合计算工时岗位：季节性生产、项目集中攻坚类岗位，执行以季度为周期的综合计算工时制，在审批周期内总实际工作时长不得超过法定标准总工时，超出部分统一按加班核算规则计发加班工资。
4. 异地派驻、异地办公员工，按办公所在地的标准时区执行对应上下班打卡时间，由部门负责人提前报备人力资源部备案，不得随意调整考勤时点。

### （二）打卡全场景规则

1. 打卡方式：全员统一使用公司指定的人脸考勤系统完成上下班打卡，禁止代打卡行为，系统自动记录打卡时间、打卡地点，数据实时同步至人力资源部考勤后台。
2. 打卡地点限制：常规办公岗位打卡地点限定为公司办公大楼指定考勤区域，外勤外出员工可使用移动端定位打卡，定位范围限定在当日工作任务对应的业务区域内，超出范围的打卡记录系统自动标记为异常。
3. 每日打卡要求：工作日每日需完成上班、下班两次有效打卡，午休时段无需打卡，漏打任意一次即标记为当日考勤记录不全，需走考勤异常补登流程。
4. 特殊场景免打卡：公司高管、经审批通过的核心外勤岗位，可申请免日常打卡权限，以工作日志、工作成果交付作为出勤核验依据，免打卡申请需经总经理审批通过后生效。

### （三）出勤类别明确定义

1. 正常出勤：在规定工作时段内全程在岗，按要求完成全部工作任务，打卡记录完整无异常。
2. 加班出勤：经提前审批通过，在法定标准工作时间之外延长工作时长，包含工作日延时加班、休息日加班、法定节假日加班三类。
3. 各类假期出勤：按公司假期管理制度提交申请并审批通过的年休假、病假、事假、婚假、产假等各类假期，按对应假期考勤规则核算。
4. 因公外出出勤：因业务对接、客户拜访、外出参会等公司指派的外出任务，不在公司办公区域但正常完成工作任务，属于有效出勤。

### （四）加班全管理规则

1. 加班审批流程：员工因工作需要确需加班的，必须提前1个工作日在内部系统提交加班申请，明确加班事由、预计加班时长，经部门负责人审批通过后方可计入有效加班，未经提前审批的自行延时行为不认定为加班。
2. 加班时长限制：工作日延时加班每日不得超过2小时，因特殊原因最长不得超过3小时，每月累计加班总时长不得超过36小时，严格符合劳动法工时上限要求。
3. 加班核算规则：工作日延时加班按员工小时工资的1.5倍核算加班工资，休息日优先安排同等时长补休，无法安排补休的按小时工资的2倍核算加班工资，法定节假日加班统一按小时工资的3倍核算加班工资，不得用补休替代法定节假日加班薪资。
4. 加班补偿时效：休息日加班产生的补休时长，需在加班发生后的3个月内使用完毕，逾期未使用的自动清零，不再折算薪资发放。

## 三、迟到早退全处理细则

### （一）迟到分级定义与处置

1. 轻度迟到：晚于规定上班时间15分钟以内到岗，当月累计前2次轻度迟到不予处罚，从第3次开始，每次扣除当日全勤奖的20%。
2. 中度迟到：晚于规定上班时间15分钟以上、不足1小时到岗，每次扣除当日半天岗位工资，同时记录一次考勤违规。
3. 重度迟到：晚于规定上班时间1小时以上、不足4小时到岗，直接按旷工半天处理，扣除当日全天基础薪资的50%。
4. 月度累计规则：自然月内累计迟到早退达到5次，额外扣除当月全勤奖全额，同时取消当月参与部门评优的资格。

### （二）早退分级定义与处置

1. 轻度早退：早于规定下班时间15分钟以内离岗，处置规则与轻度迟到完全一致。
2. 中度早退：早于规定下班时间15分钟以上、不足1小时离岗，处置规则与中度迟到完全一致。
3. 重度早退：早于规定下班时间1小时以上、不足4小时离岗，直接按旷工半天处理，处置规则与重度迟到完全一致。

### （三）旷工全场景处置

1. 旷工认定标准：未经提前审批擅自不到岗、假期到期未续假逾期不到岗、提供虚假出勤证明材料、重度迟到早退超过4小时，以上情形均直接认定为全天旷工。
2. 旷工薪资扣除：旷工1天扣除当日全额应发薪资，同时扣除当月月度绩效的10%；连续旷工达到3天，或年度累计旷工达到5天，属于严重违反公司规章制度，公司有权依法解除劳动合同，无需支付经济补偿金。
3. 旷工后续约束：员工旷工期间，公司无需承担任何薪资福利保障责任，如因旷工给公司造成直接经济损失，员工需按实际损失金额承担对应赔偿责任。

## 四、考勤异常全处理机制

### （一）常见异常场景分类

1. 漏打卡异常：当日实际正常出勤，但忘记完成人脸打卡，系统无有效打卡记录。
2. 打卡设备故障异常：考勤机临时断网、识别故障，导致员工正常到岗但无法完成打卡。
3. 外勤打卡异常：外勤外出时定位信号弱、超出预设打卡范围，系统自动标记打卡异常。
4. 突发应急异常：员工突发急病、遭遇交通意外等不可抗力因素，无法按时到岗也无法提前提交请假申请。

### （二）异常申诉与补登流程

1. 申诉时效：员工发现个人考勤记录异常，需在异常发生后的3个工作日内提交考勤异常申诉，逾期未申诉的异常记录直接按原始数据生效，不再接受补登申请。
2. 提交材料：申诉时需在内部考勤系统提交《考勤异常补登申请单》，同步附上对应佐证材料：漏打卡需提供当日在岗工作记录、同事佐证；设备故障需由行政部统一核验故障日志；外勤异常需提供当日外出工作沟通记录、对接方佐证。
3. 审批流程：考勤异常申请提交后，经部门负责人初审确认出勤真实性，人力资源部终审通过后，同步更新考勤后台数据，修正异常记录。
4. 月度补登上限：每位员工每月考勤异常补登申请最多不得超过2次，超出次数的异常记录一律按迟到、早退或旷工处置，避免随意补登破坏考勤秩序。

### （三）特殊突发场景处理

员工突发疾病、遭遇交通拥堵、突发交通意外等特殊情况，无法按时到岗且来不及提前走线上审批流程的，必须在规定上班时间后1小时内，通过微信、电话等方式告知部门负责人，事后3个工作日内补充提交对应证明材料，走异常补登流程，否则直接按迟到或旷工处置。

## 五、全周期考勤核验与归档规则

1. 每日考勤公示：每日上午10点前，考勤系统自动推送前一日全员考勤异常明细至各部门考勤对接人，同步通知异常员工及时处理。
2. 月度考勤核对：每月最后1个工作日，人力资源部导出当月全员完整考勤数据，推送至每位员工个人账号，员工需在3个工作日内完成个人考勤核对，签字确认后作为当月薪资核算的最终依据。
3. 数据归档留存：所有考勤原始记录、异常申诉材料、审批凭证统一电子归档，符合国家劳动档案管理要求，留存时长不低于2年，随时可回溯核验。
4. 年度考勤复盘：每年年末人力资源部导出全员年度考勤数据，统计员工全年迟到早退、旷工、加班、假期使用整体情况，作为下年度员工岗位晋升、薪资调整的核心参考依据之一。

## 六、监督与违规约束机制

1. 严禁代打卡：一旦发现代打卡行为，代打卡人与被代打卡人均记一次严重考勤违规，双方各扣除当月绩效的20%，累计发现2次代打卡行为，直接按严重违纪处置。
2. 严禁伪造材料：员工提交虚假医院证明、虚假外勤记录骗取正常出勤认定的，一经核实直接按旷工处理，情节严重的公司有权依法解除劳动合同。
3. 管理员权责：考勤系统管理员不得私自篡改原始考勤数据，违规操作一经发现，按公司行政管理制度严肃处置。
4. 申诉反馈通道：员工对最终考勤核算结果有异议，可向人力资源部提交书面申诉，人力资源部需在2个工作日内完成全流程复核，给出正式复核结论。
